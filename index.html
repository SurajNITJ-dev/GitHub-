Git commands

1.create any demmy project to work on git.
2. First step is to initialize the project with git so that it start tracking your version control.
1. command to initialize the project: git init
3. To check whether the project is initialized or not, use the following command:
2. la -Force
4. To check the status of changes:
3. git status
it will show your current not committed project name
5. To add the files or changese in files:
4. git add _file_name_
6. check the status of changes, it will show you added changes in green font with message "changes to be committed"
7. Now commit the changes: 5. git commit -m "message(version1)" 8. To check the branch :
6. git branch
9. To check who has commited :
7.git log
it will show the author github id with time of commitment
10. To check the previous version:
8. git log (will show you the commit id of all version)
9. git show [paste the commit id of the version to be fetched]:_file_name_
11. To switch version:
10. git checkout _commit id of switching version_ -- _us file se kya chahiye for example ek file chahiye index.html ya * for all files_
12. To return to main verison:
git checkout main -- *
13. If we made some unnecessary changes by mistake:
Case 1. changes not added using git add.. to restore back to main version type:
git restore .
Case 2. if changes were added using git add .. then type:
git restore --staged .
it will remove it form staged Then use the Case 1 to restore back to main.
Case 3:Added changess to staging are (didn't commit) after this added more changes to file:
To get the staged changes;
git restore --wokrtree index.html
Case 4:When mistake is comitted: To revert back
git reset --soft HEAD^ (uncommit and keep the changes)
or
git reset --hard HEAD^ (uncommit and discard the changes)
